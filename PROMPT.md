## 2. Проблема (подача)

### 2.1 Что происходит
В WhatsApp, Telegram и в чатах поддержки казахи массово пишут **латиницей и без особых казахских букв** (ә, ғ, қ, ң, ө, ұ, ү, һ, і):

| Как пишут на самом деле | Как правильно | Смысл |
|---|---|---|
| salem qalaisyn | Сәлем, қалайсың | Привет, как дела |
| balamnyn qyzuy koterildi | Баламның қызуы көтерілді | У моего ребёнка поднялась температура |
| kartadan aqsha ketip qaldy | Картадан ақша кетіп қалды | С карты ушли деньги |

Причины: на телефоне нет казахской раскладки или неудобно её переключать, привычка с детства, смешение с русским.

### 2.2 Почему это проблема
- Переводчики, чат-боты и автоматические системы маршрутизации учились **на правильных текстах кириллицей**.
- Чат-казахский они понимают плохо. Это мы **измерим**: насколько падает качество перевода.
- Банки, поликлиники и госуслуги всё чаще ставят ИИ первым на линию. Значит, человек, который пишет «как привык», **получает худшую помощь или не получает её вообще**.
- Это не только про казахский. Так же пишут на узбекском, кыргызском, азербайджанском, турецком, вьетнамском, йоруба. Сотни миллионов людей «невидимы» для ИИ из-за того, **как** они пишут.

### 2.3 Конкретный пользователь (обязательно по правилам)
**Гульнар-апа, 62 года, Туркестанская область.** У неё телефон без казахской раскладки. Ночью у внука поднялась температура, и она пишет в чат-бот поликлиники:
> «balamnyn qyzuy 39 koterildi ne isteu kerek»

Чат-бот (или переводчик для оператора) превращает это в бессмыслицу. Qalaisyn стоит **перед** любым ИИ-сервисом как «переводчик с чат-казахского на правильный казахский» и возвращает сообщению смысл.

**Момент, когда нужен инструмент:** любая ситуация, когда человек пишет ИИ-системе на казахском со своего телефона.

## 3. Что строим (техническое задание)

### 3.1 Задача модели
Вход: чат-казахский (латиница, без особых букв, нижний регистр, без знаков препинания, иногда с русскими словами).
Выход: правильный казахский кириллицей.

Это **задача восстановления текста** (как восстановление диакритик во вьетнамском или французском), применённая к казахскому. Модель решает неоднозначности по контексту:
- `k` → **к** или **қ**?
- `a` → **а** или **ә**?
- `o` → **о** или **ө**?
- `u` → **у**, **ұ** или **ү**?
- `i` → **і**, **и** или **ы**?
- `n` / `ng` → **н** или **ң**?
- `g` / `gh` → **г** или **ғ**?

### 3.2 Данные

**A. Чистый казахский (для обучения):**
1. Tatoeba: казахские предложения (разговорные, короткие), лицензия CC-BY.
2. Казахская Википедия (Hugging Face `wikimedia/wikipedia`, конфиг `20231101.kk`), берём часть предложений.
3. Если доступно: OPUS (OpenSubtitles kk), разговорные реплики из субтитров.

**B. Параллельные пары казахский → английский (для проверки перевода):**
1. Tatoeba: пары kaz–eng (разговорные).
2. NTREX-128: новостные предложения с казахским (публичный GitHub).
3. Если удастся получить доступ: FLORES+ (kaz_Cyrl), нужен вход в Hugging Face.

**C. Генератор чат-казахского (наш вклад, своё «ноу-хау»):**
Функция `chatify(text, profile)` превращает правильный текст в чат-текст. У каждого «пишущего» свой **профиль привычек**:

| Буква | Варианты, как её пишут |
|---|---|
| қ | q / k |
| ғ | g / gh |
| ә | a / ä / a' |
| ө | o / ö |
| ұ, ү | u / ü |
| і | i |
| ы | y / i |
| ң | n / ng |
| ш | sh / w |
| ж | zh / j |
| х, һ | h / x |
| у | u / w |
| й | i / y |
| ч, ц, ю, я | ch, ts/c, yu/iu, ya/ia |

Плюс: нижний регистр, выброшенная пунктуация, иногда пропущенные пробелы или повторённые буквы.
Профили: «Аккуратный» (q, ä, ö…), «Типичный» (q/k, a, o, u, i), «Минималист» (только базовые латинские буквы), «Смешанный» (вставки русских слов латиницей).

**D. Реальный тест от носителя (самая ценная часть, «свои данные»):**
- Жасулан пишет **50–100 сообщений** так, как реально пишет друзьям, и к каждому — правильную версию кириллицей.
- Темы: быт, учёба, здоровье, деньги, документы, срочные ситуации.
- С разрешения можно добавить сообщения друзей и родственников (только с их согласия, без личных данных).
- Этот набор **никогда** не используется в обучении, только для финальной проверки.

**Разбиение:** train / dev / test по предложениям, тест не пересекается с обучением. Реальный набор от носителя — отдельный финальный тест.

### 3.3 Модели (от простого к сильному)

| Код | Что это | Зачем |
|---|---|---|
| **B0** | Ничего не делать: чат-текст сразу идёт в переводчик | Показывает размер проблемы |
| **B1** | Простые правила: каждая латинская буква → самая частая кириллическая (k→к, a→а…) | «Простой вариант», который требуют правила |
| **B2** | Словарь: для каждого чат-слова берём самую частую правильную форму из обучающих данных | Сильный простой вариант, его надо честно победить |
| **M1 (наша)** | Генерация всех возможных вариантов слова + отбор по словарю + выбор лучшей цепочки слов по **языковой модели** (n-граммы, алгоритм Витерби) | Учитывает контекст: соседние слова решают, «кетті» это или «қатты» |
| **M2 (если успеваем)** | Дообученная байтовая нейросеть ByT5-small (GPU в Colab) | Сравнить классический метод и нейросеть |

Почему M1 хорошая основная модель: быстрая, работает на обычном компьютере, каждое решение можно объяснить жюри («модель выбрала "қызуы", потому что после "баламның" это слово встречается в 40 раз чаще»).

### 3.4 Как измеряем

**Уровень 1 — качество восстановления текста:**
- Точность по словам (word accuracy).
- Ошибка по символам (CER).

**Уровень 2 — главное: понимает ли ИИ смысл после нас:**
- Переводим на английский бесплатной моделью **NLLB-200** (`facebook/nllb-200-distilled-600M`, `kaz_Cyrl → eng_Latn`).
- Пять условий: правильный оригинал (потолок) / B0 / B1 / B2 / M1.
- Метрика: **chrF** (библиотека sacrebleu).
- **Главная цифра проекта:**
  `доля возвращённого смысла = (M1 − B0) / (Оригинал − B0)`
  Пример формулировки: «Qalaisyn возвращает 78% смысла, который терялся».

**Уровень 3 — разбивки (жюри требует результаты по группам):**
- По профилю письма (Аккуратный / Типичный / Минималист / Смешанный).
- По буквам: какие казахские буквы восстанавливать труднее всего (матрица ошибок для к/қ, а/ә, і/ы/и и т.д.).
- По длине сообщения.
- Синтетический тест против **реального теста носителя**: держится ли модель на настоящих сообщениях.

**Уровень 4 — проверка носителем (жюри это особо ценит):**
- Жасулан оценивает 30 выходов модели по шкале: «верно» / «мелкая ошибка» / «смысл искажён».
- Сравниваем его оценки с метрикой chrF: совпадают ли.

**Разбор ошибок (обязательно):**
- Минимум 5 примеров «вход → наш выход → правильно», с объяснением, почему модель ошиблась (омонимы, редкие слова, русские вставки, имена).

### 3.5 Расширение для масштаба (если успеваем)
**Перенос на кыргызский:** в кыргызском те же буквы ң, ө, ү. Меняем таблицу букв, обучаем на кыргызском тексте из Tatoeba или Википедии и показываем одну строку результата. Вывод для жюри: «метод переносится на другие тюркские языки почти бесплатно». Это сильно поднимает Impact.

## 4. Что сдаём

### 4.1 Код
GitHub-репозиторий (и/или Colab-ноутбук) `Qalaisyn`, открытый по ссылке, **с сохранёнными выходами ячеек**.

Структура ноутбука:
1. **The problem in one picture**: пример сообщения Гульнар-апа и перевод «до» (бессмыслица).
2. **Data**: загрузка, чистка, размеры наборов.
3. **Chatify**: генератор чат-текста и примеры по профилям.
4. **Baselines B0, B1, B2.**
5. **Our model M1** (+ M2, если успели).
6. **Results**: таблица и главный график.
7. **Breakdown**: по профилям, буквам, длине; синтетика против реального теста.
8. **Failure analysis**: таблица ошибок с объяснениями.
9. **Native speaker check.**
10. **Demo** (Gradio).
11. **Credits.**

### 4.2 Главный график (одна картинка, которую запомнят)
Столбики chrF перевода: **Правильный текст** (серый, «потолок») → **Чат-текст как есть** (красный, провал) → **Простые правила** → **Словарь** → **Qalaisyn** (яркий, почти до потолка). Подпись над разрывом: «Qalaisyn возвращает X% потерянного смысла».

### 4.3 Демо-страница (Gradio)
Поле ввода: «Напиши как в WhatsApp».
Вывод в три колонки:
1. Перевод чат-текста как есть (плохо).
2. Восстановленный казахский от Qalaisyn (исправленные буквы подсвечены).
3. Перевод после Qalaisyn (хорошо).
